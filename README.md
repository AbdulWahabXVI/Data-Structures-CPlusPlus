# C++ Data Structures Repository

This repository contains implementations of fundamental data structures in C++, including both standard and template-based versions.

## 📌 Contents

### Trees
- Binary Tree Node
- Binary Search Tree (BST)
- BST deletion (erase function)
- Generic Tree Template

### Linked Lists
- Singly Linked List
- Singly Linked List (Template version)
- Singly Circular Linked List
- Doubly Linked List

### Stacks
- Stack using Array
- Stack using Linked List
- Stack using Templates

### Queues
- Queue using Array
- Queue using Linked List
- Queue using Templates

## 🎯 Purpose
This project is built for learning and practicing core data structures in C++ with multiple implementations (basic, pointer-based, and template-based).

## 🛠 Language
- C++
